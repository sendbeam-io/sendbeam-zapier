# Security

## Reporting a vulnerability

Email **security@sendbeam.io**. Please do not open a public issue for anything exploitable.

Tell us what you found and how to reproduce it. How we handle reports, what you can expect to hear back, and
the safe harbour we offer are set out in our
[vulnerability disclosure policy](https://sendbeam.io/legal/security). If you would like credit, say so; if you
would rather stay anonymous, that is fine too.

## Scope

This repository is the Zapier app. Problems with **sendbeam.io itself** — the application, the API or hosted
pages — are just as welcome, reported the same way. See
<https://sendbeam.io/.well-known/security.txt>.

Problems with Zapier's own platform are for Zapier; see <https://zapier.com/legal/security>.

## Supported versions

The latest version on Zapier. Fixes ship in a new version, and existing Zaps are moved to it.
